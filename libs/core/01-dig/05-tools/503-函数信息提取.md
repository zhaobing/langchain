# `@tool` 装饰器如何自动提取 JSON Schema

本文档分析 LangChain 的 `@tool` 装饰器如何从函数签名和注释中自动提取 JSON Schema。

## 概述

`@tool` 装饰器位于 `langchain_core/tools/convert.py`，它将 Python 函数转换为具有结构化工具接口的工具，通过类型注解和 docstring 自动生成 JSON Schema。

## 核心源文件

| 文件 | 路径 | 作用 |
|------|------|------|
| `convert.py` | `langchain_core/tools/convert.py` | `@tool` 装饰器实现 |
| `base.py` | `langchain_core/tools/base.py` | `BaseTool` 基类和 schema 创建 |
| `function_calling.py` | `langchain_core/utils/function_calling.py` | Docstring 解析 |

## 工作流程

```
┌─────────────────┐    ┌──────────────────┐    ┌─────────────────┐
│   @tool 装饰器   │ -> │ StructuredTool   │ -> │   JSON Schema    │
└─────────────────┘    └──────────────────┘    └─────────────────┘
        │                       │                       │
        v                       v                       v
   函数签名处理          Pydantic 模型创建         最终 Schema 输出
   Docstring 解析        参数验证与过滤           模型绑定使用
```

## 1. 装饰器入口 (`convert.py:72-368`)

### 多种调用方式支持

```python
# 方式1: 无参数装饰
@tool
def my_func(x: int) -> str:
    """描述"""

# 方式2: 自定义名称
@tool("custom_name")
def my_func(x: int) -> str:
    """描述"""

# 方式3: 带配置参数
@tool(parse_docstring=True)
def my_func(x: int) -> str:
    """描述.

    Args:
        x: 参数说明
    """
```

### 核心参数

| 参数 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `parse_docstring` | `bool` | `False` | 是否解析 Google-style docstring |
| `error_on_invalid_docstring` | `bool` | `True` | docstring 无效时是否报错 |
| `infer_schema` | `bool` | `True` | 是否自动推断 schema |
| `args_schema` | `ArgsSchema \| None` | `None` | 手动指定 schema |

## 3. Docstring 解析 (`function_calling.py:664-721`)

### `_parse_google_docstring` 函数

### 解析规则

#### 输入示例

```python
def calculator(expression: str) -> str:
    """A simple calculator that evaluates basic mathematical expressions.

    Args:
        expression: A mathematical expression as a string (e.g., "2 + 2").

    Returns:
        The result of the mathematical evaluation.
    """
```

#### 解析过程

```python
# 1. 按双换行符分割块
docstring_blocks = docstring.split("\n\n")
# ["A simple calculator...", "Args:\n    expression: ...", "Returns:\n    ..."]

# 2. 提取描述（Args 之前的内容）
description = "A simple calculator that evaluates basic mathematical expressions."

# 3. 解析 Args 块
arg_descriptions = {
    "expression": "A mathematical expression as a string (e.g., "2 + 2")."
}
```

#### 返回值

```python

    "A simple calculator that evaluates basic mathematical expressions.",  # 函数描述
    {"expression": "A mathematical expression as a string..."}  # 参数描述
)
```

### 验证规则

当 `error_on_invalid_docstring=True` 时：

```python
# base.py:169-184
def _validate_docstring_args_against_annotations(
    arg_descriptions: dict,
    annotations: dict
) -> None:
    for docstring_arg in arg_descriptions:
        if docstring_arg not in annotations:
            raise ValueError(
                f"Arg {docstring_arg} in docstring not found in function signature."
            )
```

无效的 docstring 示例：

```python
# 错误1: 没有 Args 块
def invalid_1(x: int) -> int:
    """Invalid."""
    pass

# 错误2: Args 块前缺少空行
def invalid_2(x: int) -> int:
    """Invalid.
    Args:
        x: The x."""
    pass

# 错误3: docstring 中的参数不在函数签名中
def invalid_3(x: int) -> int:
    """Invalid.

    Args:
        y: Not in signature."""
    pass
```

## 4. 类型注解增强

### `Annotated` 类型支持

从 `Annotated[type, description]` 提取描述：

```python
# base.py:100-114
def _get_annotation_description(arg_type: type) -> str | None:
    if _is_annotated_type(arg_type):
        annotated_args = get_args(arg_type)
        for annotation in annotated_args[1:]:
            if isinstance(annotation, str):
                return annotation
    return None
```

### `_infer_arg_descriptions` 综合推断

```python
# base.py:187-218
def _infer_arg_descriptions(
    fn: Callable,
    *,
    parse_docstring: bool = False,
    error_on_invalid_docstring: bool = False,
) -> tuple[str, dict]:
    annotations = typing.get_type_hints(fn, include_extras=True)

    if parse_docstring:
        # 优先使用 docstring 中的描述
        description, arg_descriptions = _parse_python_function_docstring(
            fn, annotations, error_on_invalid_docstring=error_on_invalid_docstring
        )
    else:
        description = inspect.getdoc(fn) or ""
        arg_descriptions = {}

    # 补充 Annotated 类型的描述
    for arg, arg_type in annotations.items():
        if arg not in arg_descriptions:
            if desc := _get_annotation_description(arg_type):
                arg_descriptions[arg] = desc

    return description, arg_descriptions
```

## 6. 完整示例解析

以 `test_tools_dig.py` 中的 `calculator` 工具为例：

```python
@tool
def calculator(expression: str) -> str:
    """A simple calculator that evaluates basic mathematical expressions.

    Args:
        expression: A mathematical expression as a string (e.g., "2 + 2", "10 * 5").

    Returns:
        The result of the mathematical evaluation as a string.
    """
    try:
        result = eval(expression, {"__builtins__": {}}, {})
        return str(result)
    except Exception as e:
        return f"Error: {e}"
```

| 4 | 解析 Args | `arg_descriptions = {"expression": "A mathematical expression..."}` |

## 8. 总结

`@tool` 装饰器的 JSON Schema 提取机制综合运用了：

1. **Python 内省**: `inspect.signature()`, `get_type_hints()`
2. **Pydantic 验证**: `validate_arguments()` 自动创建模型
3. **Docstring 解析**: Google-style 规范解析
4. **类型增强**: `Annotated` 类型元数据提取

这种设计使得开发者只需编写符合 Python 规范的函数（类型注解 + docstring），就能自动获得符合 OpenAI Function Calling 格式的 JSON Schema。
