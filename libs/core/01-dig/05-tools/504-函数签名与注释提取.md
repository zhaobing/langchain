# 函数签名与注释提取 JSON Schema 详解

本文档深入分析 `langchain_core.tools.base` 中的三个核心方法，详细说明如何从 Python 函数的**签名**和**docstring**中自动提取 JSON Schema。

## 核心方法概览

| 方法 | 文件 | 行号 | 作用 |
|------|------|------|------|
| `create_schema_from_function` | `base.py` | 279-375 | 主入口，协调整个 schema 创建流程 |
| `_infer_arg_descriptions` | `base.py` | 187-218 | 推断参数描述（从 docstring 或 Annotated） |
| `_create_subset_model` | `utils/pydantic.py` | 273-300 | 创建子集模型并生成最终 schema |

## 完整数据流


## 1. `create_schema_from_function` - 主入口方法

**位置**: `base.py:279-375`

### 方法签名

```python
def create_schema_from_function(
    model_name: str,
    func: Callable,
    *,
    filter_args: Sequence[str] | None = None,
    parse_docstring: bool = False,
    error_on_invalid_docstring: bool = False,
    include_injected: bool = True,
) -> type[BaseModel]:
```

### 处理流程分解

#### Step 1: 获取函数签名

```python
# base.py:306
sig = inspect.signature(func)
```

**输入示例**：
```python
def calculator(expression: str, precision: int = 2) -> str:
    """计算表达式.

    Args:
        expression: 要计算的表达式
        precision: 精度
    """
    pass
```

**输出**：
```python
<Signature (expression: str, precision: int = 2) -> str>
```

#### Step 2: 使用 Pydantic 创建验证模型

```python
# base.py:308-317
if _function_annotations_are_pydantic_v1(sig, func):
    validated = validate_arguments_v1(func, config=_SchemaConfig)
else:
    # 使用 Pydantic 的 validate_arguments 装饰器
    # 这会自动从函数签名创建一个 Pydantic 模型
    validated = validate_arguments(func, config=_SchemaConfig)

inferred_model = validated.model
```

**`validate_arguments` 的作用**：

| 功能 | 说明 |
|------|------|
| 类型提取 | 从函数签名提取参数的类型注解 |
| 模型创建 | 创建一个包含所有参数的 Pydantic 模型 |
| 验证器生成 | 自动生成参数验证逻辑 |
| 默认值处理 | 保留函数参数的默认值 |

**创建的 `inferred_model` 结构**：

```python
# inferred_model (内部结构)
class CalculatorValidator:
    expression: str                    # 必需参数
    precision: int = 2                 # 带默认值
    args: tuple = ()                   # Pydantic 添加的虚拟字段
    kwargs: dict = {}                  # Pydantic 添加的虚拟字段
```

#### Step 3: 确定需要过滤的参数

```python
# base.py:334-348
FILTERED_ARGS = ("run_manager", "callbacks")

if filter_args:
    filter_args_ = filter_args
else:
    # 处理类方法的 self/cls
    existing_params = list(sig.parameters.keys())
    if existing_params and existing_params[0] in {"self", "cls"} and in_class:
        filter_args_ = [existing_params[0], *list(FILTERED_ARGS)]
    else:
        filter_args_ = list(FILTERED_ARGS)

    # 可选：排除 injected 参数
    for existing_param in existing_params:
        if not include_injected and _is_injected_arg_type(sig.parameters[existing_param].annotation):
            filter_args_.append(existing_param)
```

**过滤规则**：

| 参数类型 | 是否过滤 | 示例 |
|----------|----------|------|
| `self` / `cls` | ✅ (类方法) | 类方法的第一个参数 |
| `run_manager` | ✅ | LangChain 内部参数 |
| `callbacks` | ✅ | LangChain 内部参数 |
| `InjectedToolArg` | ✅ (可选) | 运行时注入的参数 |
| 业务参数 | ❌ | 保留在 schema 中 |

#### Step 4: 推断参数描述

```python
# base.py:350-354
description, arg_descriptions = _infer_arg_descriptions(
    func,
    parse_docstring=parse_docstring,
    error_on_invalid_docstring=error_on_invalid_docstring,
)
```

**返回值**：
```python
(
    "计算表达式.",           # 函数描述
    {
        "expression": "要计算的表达式",
        "precision": "精度"
    }                       # 参数描述字典
)
```

#### Step 5: 筛选有效字段

```python
# base.py:356-367
valid_properties = []
for field in get_fields(inferred_model):
    # 过滤 Pydantic 的虚拟字段
    if not has_args and field == "args":
        continue
    if not has_kwargs and field == "kwargs":
        continue
    if field == "v__duplicate_kwargs":  # Pydantic 内部字段
        continue
    # 过滤用户指定的参数
    if field not in filter_args_:
        valid_properties.append(field)
```

**示例结果**：
```python
# 对于 calculator(expression, precision)
valid_properties = ["expression", "precision"]
# "args", "kwargs", "v__duplicate_kwargs" 被过滤
```

#### Step 6: 创建子集模型

```python
# base.py:369-375
return _create_subset_model(
    model_name,
    inferred_model,
    list(valid_properties),
    descriptions=arg_descriptions,
    fn_description=description,
)
```

## 2. `_infer_arg_descriptions` - 推断参数描述

**位置**: `base.py:187-218`

### 方法签名

```python
def _infer_arg_descriptions(
    fn: Callable,
    *,
    parse_docstring: bool = False,
    error_on_invalid_docstring: bool = False,
) -> tuple[str, dict]:
```

### 处理流程

#### Step 1: 获取类型注解

```python
# base.py:203
annotations = typing.get_type_hints(fn, include_extras=True)
```

**`include_extras=True` 的作用**：保留 `Annotated` 类型的元数据。

```python
# 示例
from typing import Annotated

def process(
    data: Annotated[str, "输入数据"],
    count: int
) -> str:
    pass

# include_extras=True
annotations = {
    "data": Annotated[str, "输入数据"],
    "count": int
}

# include_extras=False (默认)
annotations = {
    "data": str,      # 描述信息丢失
    "count": int
}
```

#### Step 2a: 解析 Docstring（如果启用）

```python
# base.py:204-207
if parse_docstring:
    description, arg_descriptions = _parse_python_function_docstring(
        fn, annotations, error_on_invalid_docstring=error_on_invalid_docstring
    )
else:
    description = inspect.getdoc(fn) or ""
    arg_descriptions = {}
```

**`_parse_python_function_docstring` 流程**：

```python
# function_calling.py:664-721
def _parse_google_docstring(docstring, args, error_on_invalid_docstring):
    # 1. 按双换行符分割
    docstring_blocks = docstring.split("\n\n")

    # 2. 提取描述（Args 之前的部分）
    descriptors = []
    for block in docstring_blocks:
        if block.startswith("Args:"):
            break
        descriptors.append(block)
    description = " ".join(descriptors)

    # 3. 解析 Args 部分
    arg_descriptions = {}
    for line in args_block.split("\n")[1:]:
        if ":" in line:
            arg, desc = line.split(":", maxsplit=1)
            arg = arg.strip()
            arg_descriptions[arg] = desc.strip()
    return description, arg_descriptions
```

#### Step 2b: 验证 Docstring（如果启用）

```python
# base.py:211-212
if parse_docstring:
    _validate_docstring_args_against_annotations(arg_descriptions, annotations)
```

**验证规则**：确保 docstring 中的参数都在函数签名中存在。

```python
# base.py:169-184
def _validate_docstring_args_against_annotations(arg_descriptions, annotations):
    for docstring_arg in arg_descriptions:
        if docstring_arg not in annotations:
            raise ValueError(
                f"Arg {docstring_arg} in docstring not found in function signature."
            )
```

#### Step 3: 补充 Annotated 描述

```python
# base.py:213-217
for arg, arg_type in annotations.items():
    if arg in arg_descriptions:
        continue  # 已从 docstring 获取
    if desc := _get_annotation_description(arg_type):
        arg_descriptions[arg] = desc
```

**`_get_annotation_description` 实现**：

```python
# base.py:100-114
def _get_annotation_description(arg_type: type) -> str | None:
    if _is_annotated_type(arg_type):
        annotated_args = get_args(arg_type)
        for annotation in annotated_args[1:]:  # 跳过类型本身
            if isinstance(annotation, str):
                return annotation
    return None
```

**优先级顺序**：

```
Docstring Args 描述 > Annotated 描述 > 无描述
```

### 完整示例

**输入函数**：
```python
def search(
    query: Annotated[str, "搜索关键词"],
    limit: Annotated[int, "结果数量上限"],
    source: str = "web"
) -> str:
    """执行搜索.

    Args:
        query: 要搜索的内容
        limit: 返回的最大结果数
        source: 搜索源 (web/news/images)
    """
    pass
```

**输出结果**：
```python
(
    "执行搜索.",           # description
    {
        "query": "要搜索的内容",      # Docstring 优先
        "limit": "返回的最大结果数",   # Docstring 优先
        "source": "搜索源 (web/news/images)"
    }                       # arg_descriptions
)
```

## 3. `_create_subset_model` - 创建子集模型

**位置**: `utils/pydantic.py:273-300`

### 方法签名

```python
def _create_subset_model(
    name: str,
    model: TypeBaseModel,
    field_names: list[str],
    *,
    descriptions: dict | None = None,
    fn_description: str | None = None,
) -> type[BaseModel]:
```

### 版本兼容处理

```python
# utils/pydantic.py:286-300
if issubclass(model, BaseModelV1):
    return _create_subset_model_v1(
        name, model, field_names,
        descriptions=descriptions,
        fn_description=fn_description,
    )
return _create_subset_model_v2(
    name, model, field_names,
    descriptions=descriptions,
    fn_description=fn_description,
)
```

### Pydantic V2 实现 (`_create_subset_model_v2`)

**位置**: `utils/pydantic.py:231-266`

#### Step 1: 构建字段定义

```python
# utils/pydantic.py:240-248
descriptions_ = descriptions or {}
fields = {}
for field_name in field_names:
    field = model.model_fields[field_name]
    description = descriptions_.get(field_name, field.description)
    field_info = FieldInfoV2(
        description=description,
        default=field.default
    )
    if field.metadata:
        field_info.metadata = field.metadata
    fields[field_name] = (field.annotation, field_info)
```

**字段构建示例**：

```python
# 原始字段
field = model.model_fields["expression"]
# field.annotation = str
# field.default = ... (required)
# field.description = None

# 新字段
fields["expression"] = (
    str,                           # annotation
    FieldInfoV2(
        description="要计算的表达式",  # 从 arg_descriptions 获取
        default=...                  # 保留原默认值
    )
)
```

#### Step 2: 创建新模型

```python
# utils/pydantic.py:250-252
rtn = _create_model_base(
    name, **fields,
    __config__=ConfigDict(arbitrary_types_allowed=True)
)
```

**等价于**：

```python
from pydantic import create_model, Field

CalculatorInput = create_model(
    "CalculatorInput",
    expression=(str, Field(..., description="要计算的表达式")),
    precision=(int, Field(default=2, description="精度"))
)
```

#### Step 3: 保留注解和文档

```python
# utils/pydantic.py:254-265
# 保留 __annotations__ 用于类型检查
selected_annotations = [
    (name, annotation)
    for name, annotation in model.__annotations__.items()
    if name in field_names
]
rtn.__annotations__ = dict(selected_annotations)

# 设置模型的 __doc__
rtn.__doc__ = textwrap.dedent(fn_description or model.__doc__ or "")
```

## 完整示例追踪

### 输入函数

```python
from typing import Annotated

def calculate(
    expression: Annotated[str, "数学表达式"],
    precision: int = 2
) -> float:
    """执行数学计算.

    Args:
        expression: 要计算的数学表达式
        precision: 小数点精度

    Returns:
        计算结果
    """
    return eval(expression)
```

### 执行流程

```
create_schema_from_function("CalculateInput", calculate, parse_docstring=True)
│
├─> inspect.signature(calculate)
│   └─> <Signature (expression: Annotated[str, '数学表达式'], precision: int = 2) -> float>
│
├─> validate_arguments(calculate, config=_SchemaConfig)
│   └─> inferred_model (包含 expression, precision, args, kwargs)
│
├─> _infer_arg_descriptions(calculate, parse_docstring=True)
│   ├─> get_type_hints(calculate, include_extras=True)
│   │   └─> {"expression": Annotated[str, "数学表达式"], "precision": int, "return": float}
│   ├─> _parse_python_function_docstring(...)
│   │   ├─> description = "执行数学计算."
│   │   └─> arg_descriptions = {"expression": "要计算的数学表达式", "precision": "小数点精度"}
│   └─> return ("执行数学计算.", {"expression": "要计算的数学表达式", "precision": "小数点精度"})
│
├─> filter_args = ["run_manager", "callbacks"]
├─> valid_properties = ["expression", "precision"]  # 过滤掉 args, kwargs
│
└─> _create_subset_model("CalculateInput", inferred_model, ["expression", "precision"], ...)
    └─> CalculateInput (Pydantic 模型)
```

## 关键设计点总结

### 1. 为什么使用 `validate_arguments`？

| 特性 | 说明 |
|------|------|
| 自动类型转换 | 利用 Pydantic 的验证逻辑 |
| 处理复杂类型 | Union、Optional、List 等 |
| 默认值保留 | 自动提取函数参数的默认值 |
| 代码复用 | 避免重复实现类型推断逻辑 |

### 2. 为什么需要 `_create_subset_model`？

| 原因 | 说明 |
|------|------|
| 过滤内部字段 | `args`、`kwargs` 是 Pydantic 添加的虚拟字段 |
| 添加描述 | 将 docstring/Annotated 的描述注入到字段中 |
| 版本兼容 | 统一处理 Pydantic v1 和 v2 的差异 |

### 3. 描述信息优先级

```
Docstring (parse_docstring=True)
    ↓ (如果没有)
Annotated 类型注解
    ↓ (如果没有)
Pydantic Field 描述 (如果有)
    ↓ (如果没有)
空字符串
```
